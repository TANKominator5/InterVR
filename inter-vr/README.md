## Interviewer selection

The dashboard offers Michael (male) and Bella (female), with matching voices.
The choice is saved in `interview_sessions.interviewer`, so resumed interviews
retain their interviewer. Your last choice is also remembered on this device.

For an existing database, run
`supabase/migrations/202610050001_interviewer_choice.sql` in the Supabase SQL
editor before starting new interviews. New databases use `supabase_setup.sql`,
which already includes the column. Older sessions default to Michael.

Visit `/interviewer-preview` to switch between both characters and check their
speech, facial poses, and movement without starting a monitored interview.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
